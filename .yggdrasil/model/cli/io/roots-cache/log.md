Roots convention mining is about to gain a git-history layer that needs durable, gitignored derived state beyond the model snapshot: a content-addressed cache of parsed historical blobs so a re-index never re-parses the same file revision twice, a replay-state store so an index can resume from where a previous run left off instead of re-walking the whole history every time, and an exclusive build lock so two concurrent writers never corrupt that cache. This node establishes the storage contracts those three concerns need — one file per cached blob, an all-or-nothing six-file replay state that a partial or torn write can never masquerade as a valid resume point, and a lock that waits briefly for a concurrent writer before refusing rather than either blocking forever or racing it.
