## [2026-09-26T20:39:48.497Z]
Tests that made temporary directories and never removed them filled the development container /tmp with tens of thousands of directories in two days, most of the volume being the module cache vitest itself leaves per run. Temporary directories now come from one helper that removes them when their test file finishes, and the run points TMPDIR at one directory of its own that is removed afterwards together with the vitest cache, failing the run with the names of anything a test left behind so a new leak is caught the run it appears.
## [2026-09-27T01:47:57.513Z]
Added a helper that asserts on the stable parts of the CLI output (issue codes, causes, next commands, block labels, the verdict line, error codes) and a scanner that finds assertions pinning a sentence of prose. About one in three of the suite's assertion calls matched a literal sentence, so every rewording of the output broke tests across the tree although no behaviour changed; the golden corpus already records the exact words once. The tests README now states the convention: behaviour tests ask their question of codes and fields, and a sentence is asserted only where the wording is itself the contract.
