## [2026-09-23T20:09:58.726Z]
Several of the graph's self-governance claims could drift without any rule noticing: which rule scripts the rule-script node owns, whether two architecture types classify the same file, whether descriptions still name a removed command, and whether an enforced rule still calls itself advisory. None of these is expressible as a rule over the graph's own files, so they are held here as repository invariants, together with unit tests for the two node-level rules a single-file drill cannot exercise because they need graph context.
## [2026-09-27T01:47:57.972Z]
Added a ratchet on prose assertions in end-to-end tests. Each end-to-end file may hold at most the number of five-word literal assertions it had when the guard arrived, and the count only goes down: a new sentence assertion fails with its file and line, and a conversion must lower the committed baseline. The alternative, failing on every existing prose assertion at once, would have blocked the suite on about a thousand assertions that are converted gradually. The golden corpus and the docs-sample test are not counted because the wording is what they test.
## [2026-09-27T21:23:18.996Z]
The guards that compare a generated file with its source used to rewrite that file when an environment variable was set, so a test behaved differently depending on the shell it ran in, which the test-determinism rule forbids. The rendering moved into shared modules beside the guards, the guards now only read, and the writing lives in one developer command, generated-files.update.ts, that Vitest runs only under its own update config; each existing npm update script runs one step of it and then the guard, and writes the same bytes as before.
