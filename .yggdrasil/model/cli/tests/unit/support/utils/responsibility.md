# Utils Unit Tests — Responsibility

Guards determinism of primitives that drift detection, context budget, and search depend on. Broken hashes → every approval baseline invalid. Broken path normalization → file mappings fail cross-platform. Broken token estimation → budget warnings fire incorrectly. Broken git timestamp extraction → drift baselines lose temporal ordering. Broken tokenizer → search ranking becomes non-reproducible. Broken debug-log → diagnostic capture interferes with agent-visible output or leaks across invocations (idempotency, binary chunk handling, exit marker behavior).
