## [2026-09-27T00:47:28.612Z]
New home for what yg impact computes: the pairs an edit to a file invalidates, the cost of re-verifying a component, a file, a rule or a type, and the blast radius of a change to a rule, a flow or a type. All of it lived in command-layer support beside the text that words it, where only hygiene rules applied and the engine's rules (no direct file access, no process, determinism, the reserved graph queries) could not. It now returns plain data and the formatter words it. The only change in behaviour is none: the descendant list is taken from the one hierarchy walk the graph helpers own instead of a private copy, sorted as before, and the reviewer calls a pair bills are resolved by one helper where four loops each repeated it.
## [2026-09-27T05:56:45.123Z]
A flow blast radius now counts every participant it lists, descendants included, when it says how many would become unverified. Descendants of a declared participant receive the flow rules, so they re-open like the declared ones; counting only the declared participants under-stated the cost of editing the flow.
