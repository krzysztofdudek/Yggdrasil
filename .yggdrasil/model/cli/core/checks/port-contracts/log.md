A port is a contract, and a contract with no test is only a declaration. Naming the test makes the contract executable; recording what that test contained at a given contract version is what makes it hold. The record is kept per version and never overwritten, so a version that was used before stays bound to the contract it named — returning to that version returns to that contract instead of silently baselining whatever is on disk now. A contract test that cannot be read records nothing and reports a blocking failure: baselining an unreadable contract would be a green over something nobody checked. This is built in rather than expressed as a rule of the graph because there is nothing here for an author to sharpen or to waive: the comparison is a content hash, and a contract a consumer could waive is not a contract.
