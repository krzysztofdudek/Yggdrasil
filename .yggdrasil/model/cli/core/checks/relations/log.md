## [2026-05-29T22:21:13.089Z]
The graph validation checks were extracted from a single oversized validator module into domain-grouped modules (architecture, aspects, mapping and coverage, relations and flows) plus a small shared helper, leaving the orchestrator that runs every check and assembles the result in place to compose them. The move was verbatim: no change to which rules run, their order, their diagnostic messages, or their verdicts. The motivation is that one very large source file degrades reviewer accuracy and risks context-window truncation that can spuriously reject unchanged code; keeping each unit small enough to be reviewed in full removes that failure mode.
## [2026-05-30T14:09:01.400Z]
The per-aspect language declaration was removed from the system. An aspect that ships a parsed-tree check used to carry a `language:` list naming the languages it targeted, and the system validated that list with four dedicated checks. Nothing in the runtime ever read it: the engine already determines each source file's language from its file extension through one shared registry, then loads the matching grammar. The declaration was therefore inert metadata that could silently disagree with what the engine actually parsed — an authoritative-looking field that governed nothing.

This change deletes the field, the validators that policed its shape, and the documentation and tests that described it, and promotes the extension-to-grammar registry to the single authority for matching a file to its parser. The motivation is to remove a confusing mismatch between what an aspect claimed about languages and what the engine did, and to collapse the duplicated extension-knowledge that had drifted into more than one place.

The language a parsed-tree check sees for a given file is now derived solely from that file's extension; an unrecognized extension yields no parsed tree rather than a per-aspect error. The drift identity of a graph-aware structural check is deliberately held stable across this change so existing approvals are not invalidated by metadata that never affected behavior.

## [2026-07-10T19:28:47.736Z]
The high-fan-out warning now compares a component's direct-relation count against a per-component ceiling when the component declares one, and against the strict global default otherwise. Motivation: some components are deliberate single-responsibility seams — one auditable gateway to a subsystem, or one orchestrator coordinating a whole operation — where a high number of direct dependencies is the intended design, and splitting them to satisfy a single global limit would defeat their purpose. The global default stays strict for every component without an override, and a component still warns when it exceeds its OWN declared ceiling, so the allowance sanctions one specific, reviewed number rather than loosening the warning for everyone. This is the anti-Goodhart property: the escape hatch keeps the exception explicit and auditable in the model, and it cannot silence a component that is genuinely over-connected beyond the number it declared.
## [2026-07-10T20:42:26.267Z]
Clarified the rationale for the per-node direct-relation ceiling override so it states the declared limit SETS that node's own ceiling, replacing the global default for it, rather than only raising it. The declared limit may be higher than the global (a deliberate single-responsibility seam that concentrates coupling by design) or lower (holding one node to a stricter budget than the rest of the repo); only the stricter direction adds warnings. The check logic was already correct; this aligns the surrounding explanation with the actual behavior so a future reader does not assume the field can only loosen the limit.
## [2026-07-20T04:43:30.880Z]
The dependency-cycle detector colors each node as fully explored once its subtree is done, and relies on that coloring to avoid re-traversing shared subgraphs. On the branches where it discovers a cycle and unwinds early, it was returning without recording the node as explored, leaving the coloring inconsistent for the rest of the walk. The detector now marks a node explored on those early-return branches too, so the coloring invariant holds whether or not a cycle was found, and shared portions of the graph are not needlessly revisited or misreported.
