Adds the check that keeps a copied rule a copy. Law installed from another repository is recorded file by file when it arrives, and this compares that record against what is on disk, refusing an edited file, a missing one, and — the case with teeth — a file sitting among the copies that no installed package accounts for, since dropping your own rule script beside someone else's is how a rule nobody agreed to would wear a package's name. It is built into the gate rather than written as a rule of its own, deliberately: a rule has a script a repository can sharpen and a marker a repository can suppress, and the entire value of installing law from elsewhere is that what runs is what was published. A check you can switch off does not carry that. The installing repository's own adaptation file is never recorded and never judged here, because it is the one place a repository is meant to write; objecting to it would leave nowhere to adapt a rule at all. The same comparison backs the update and listing commands, so what the gate calls tampering and what an update refuses to overwrite can never drift into two different questions. A repository with no packages does no work: both sides of the comparison are empty.
