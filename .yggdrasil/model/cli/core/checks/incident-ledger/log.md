Guards the incident ledger's one integrity property: its append-only entries must stay in ascending time order. Because the ledger is the only external reality check the tower has, it must never be able to break the build — a hand-edit or a reordering merge that shuffles the dates is a warning, never an error, and an absent ledger is silent. There is deliberately no content-hash baseline in this first version: a hash that could go stale would give the ledger the power to block CI, which is exactly the power testimony must not have. The check delegates the file read to the persistence layer and only compares parsed datetimes, so it stays a pure ordering check with no direct file access of its own.
