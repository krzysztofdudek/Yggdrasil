The parts of the review-writing stage that belong to no single step now have an owner of their own: the stage's public contract and the pure per-pair gate predicates, the shared outcome shapes and the read-bytes helper, the bounded worker pool with its per-item failure isolation, and the shared parsed-source caches that let every subject of one rule on one component reuse a single parse. None of these decide anything about a run — they hold no recorded state, write nothing, and never contact a model. They were already written to sit beneath the stage rather than inside it, each saying in its own header that it lives apart so the stage's modules can share it without depending on each other in a circle; giving them a component makes that arrangement something the architecture can hold to rather than a convention that survives only while everyone remembers it. It matters now because the code that talks to a model became separate: both it and the orchestrator stand on these primitives, so leaving them inside either one would force the other to depend back on it, and a two-way dependency between components is refused.
