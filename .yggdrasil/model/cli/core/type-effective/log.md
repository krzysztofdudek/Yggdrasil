New pure engine computing which architecture-attached rules apply to a source file that is enforced only through its matched type, with no explicit component of its own. It walks the type's implicit parent chain (stopping at a fork, at an absent or empty parent list, or on a revisit), reuses the one existing aspect cascade against a throwaway view built for a single call, and derives relation facts for a when: predicate from a statically-resolved import edge instead of a declared node relation. It exists so file-level and component-level rule sets are computed by the exact same machinery rather than by a second, drifting implementation.

The new function excludes whole-unit rules (an aggregate still passes through, since it has no scope of its own and the ordinary per-node cascade already treats it the same way).
