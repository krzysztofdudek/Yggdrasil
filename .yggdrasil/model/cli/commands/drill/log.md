## [2026-07-11T03:28:01.669Z]
New command that re-runs a rule against its own library of pass/fail example files so a maintainer can confirm the rule still behaves as intended — for free when the rule is checkable locally, or through the real reviewer for judgment-based rules, printing the reviewer-call budget before the first call. It never touches saved verdicts; it only writes a local, gitignored results log plus, for reviewer-based cases, one telemetry line each. Failure output deliberately shows only the example label, content hashes, and pass/fail — never the example source — because this is a regression fixture for sharpening a rule, not a sensitivity or specificity measurement, and the committed example set is already visible to the author by definition. Exit is 1 on any MISS or FALSE-ALARM, 2 when some example could not be evaluated, and 0 when clean.
