## [2026-06-19T05:43:18.816Z]
Introduces a read-only command that serves the field reference for each graph element (node, aspect, architecture, config, flow). The references are embedded in the CLI binary and resolve without loading a project graph, so every reader — agent or human — consults a single source that travels with the tool, rather than per-project copies of schema files that can drift apart between projects or go stale after an upgrade. The command mirrors the existing knowledge-browser surface: a list subcommand and a read subcommand that prints one schema's reference, with an unknown name reported as a clear what/why/next error.
## [2026-07-20T04:43:29.381Z]
Requesting a schema by name must reject an unknown name with the guided list of valid names. The lookup previously treated any truthy value as a hit, so an inherited object-prototype member name could pass as a valid schema and then crash while rendering it, yielding the generic this-is-a-bug abort instead of the helpful unknown-schema error. The lookup now checks for an own property, matching the knowledge-topic lookup, so only real schemas resolve.
## [2026-09-23T22:03:17.580Z]
Command errors now go through the shared CLI output layer (fail, or failAndExit where the command exits at once) instead of each command writing its own red Error: what/why/next line to stderr, and the commands that kept a private failWith or emitError copy of that line now use the shared one. The words a reader sees are unchanged. One place now owns how a command error reads and where it goes, so wording and stream can change once for every command, and an invocation that answers in JSON can be given a machine-readable error instead of nothing on stdout.
