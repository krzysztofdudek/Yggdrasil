Introduces the ability to act on an attention item — dismiss it, or defer it to a date — with a mandatory human-signed reason on every action. The command resolves the item against the current live signals, captures the exact evidence the item carries at that moment, and records one committed decision line so the precedent survives across machines and merges cleanly across branches. An empty reason, an unknown item id, or a mis-shaped defer date is rejected before anything is written, because a recorded decision is committed case law and must always carry its justification. Acting is never silent: the reason text comes from the person, and the command only executes on their explicit instruction.

## [2026-07-12T14:42:31.208Z]
The always-read attention feed renders each item under a stable identity that embeds raw repository-derived strings (a file path, a diagnostic case label). Those identities — printed under each item on request, listed back when a dismiss or defer names an item that is not live, and echoed on a successful dismiss or defer — now pass through the same control-byte neutralization the feed already applied to every other quoted repository value. A control byte, escape sequence, or line break carried in a repository string can therefore no longer reach an agent reading the feed and be mistaken for an instruction. This neutralization is applied only to the rendered form: the underlying item identity stays byte-for-byte intact, so an item remains matchable when it is dismissed or deferred and the recorded decision still binds to the exact evidence. Separately, the cross-distance dependency line on the feed now reports the same number the structural view actually shows (its farthest few), rather than the entire cross-tree dependency universe, so the pointer to "run the structural view to see them" is literally exact.
