The attention command now reads recent version-control history (read-only) to measure how often each component's files have changed, and feeds that into the new uncovered-hot-spot suggestion. The history read lives here at the command boundary rather than in the pure engine, so the engine keeps its deterministic, no-input/output contract; only the counting and phrasing happen downstream over the data passed in.

An honesty constraint governs the missing-data case: if the history cannot be read at all — the project is not under version control, or it is a shallow clone that lacks the history — the whole change-frequency signal is omitted rather than reported as zero activity. Reporting zero would both wrongly clear a genuinely busy component and risk fabricating a signal over history that was never seen; omitting it keeps the suggestion truthful about what it actually observed.

The look-back window is a deliberate parameter, not an incidental default. Because the change count and the window are part of the evidence each suggestion is bound to, changing the window re-bases the entire class: counts shift and any hot spot a human previously set aside returns as new. That is correct — a different window is a different measurement — but it is treated as a deliberate re-baseline of the class rather than a silent tweak, and is worth revisiting only if the project's commit cadence makes the current window span too little or too much real time to be a useful "recent" horizon.

The distinction that matters is between an unknown history and a fully-known history that simply shows no recent change to a component. Unknown history — no version control, or a shallow checkout that cannot confirm the full past — means the whole signal is omitted. A fully-known history that happens to record no recent change to a component means the signal runs and honestly reports nothing for it. The probe that tells a shallow checkout apart from a complete one is itself read-only, and if that probe cannot run at all the outcome falls back to the same honest silence.
