Adds the two commands that make convention mining usable from the command line: one that reads the repository and writes a committed snapshot of the patterns it finds, and one that reports what the last such run found without ever failing a build on its own. Both stay fully dormant on a project that has not opted in — nothing is read, written, or changed anywhere else in the CLI until a roots configuration block exists. Running the mining command on a project with no such block adds one with sensible defaults automatically, printing what it added before doing anything else, so getting started never requires hand-authoring configuration first. A real problem — no initialized project here, or a genuinely broken configuration — still stops the mining command with a clear explanation of what to fix; a repository that simply has nothing interesting to report is not treated as a failure.
