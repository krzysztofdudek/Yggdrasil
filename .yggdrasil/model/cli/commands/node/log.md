A layer above the agent — an orchestrator that derives work from the architecture graph — needs to know what a component IS without reading prose or parsing the graph's own files by hand. A higher layer that reads a lower layer's file format directly breaks at the first change to that format, so the graph has to answer for itself. This component is that answer for one component of the graph: its identity, the files it owns, the dependencies it declares, the contracts it publishes, and its place in the hierarchy — offered as a text view for a person and as a versioned machine document for a tool, both rendered from the same assembled facts so the two can never disagree. It carries no rule set on purpose: what a subject must satisfy is the context package's answer, assembled from the full cascade with each rule's effective status, and a partial copy here would give a consumer two places to learn one fact and one of them to get wrong. A port's declared consumer obligations are not that copy — they are the contract the port itself publishes, and so belong to the component's structure.
