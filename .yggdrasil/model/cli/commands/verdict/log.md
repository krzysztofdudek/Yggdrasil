A rule judged by a model leaves a repository with no key holding a graph nobody can turn green, and in a horde the natural judge is often the verifier already reading the change rather than a provider anyone configured. This channel lets such a judge take the exact package a provider would have received, decide, and record the decision under its own name — without the decision bypassing what makes any verdict trustworthy. The binding is the whole point: the judgement is stored against the same content hash a provider's would have been, so it is re-proved later by hashing alone, with no key and no judge present, and stops applying the moment the code it judged moves. Refusing a stale hash is not a nicety but the mechanism: without it a judgement made against one state of the code could be attached to another, and everything downstream would rest on a claim nobody ever made. Recording is deliberately not approving; it settles one pending pair and leaves every human decision about waivers and statuses exactly where it was.
