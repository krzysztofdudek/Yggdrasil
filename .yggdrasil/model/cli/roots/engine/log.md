## [2026-08-19T13:54:21.328Z]
Field partitioning now matches the documented 300-scope floor precisely: a partition that never reaches the floor, even after folding into the repository-wide bucket, is dropped from mining entirely rather than silently assigned to that bucket, and a large partition's own survival no longer depends on what happens to unrelated small ones sharing the same repository. Extraction's error tolerance now recovers every clean scope sitting next to a malformed one, including inside a container whose other members parse fine, instead of discarding the whole container because one descendant failed to parse. The "grammar declares this construct" applicability test for the per-node-type behavioral surface is now read off each grammar's own declared vocabulary, captured once at parse time, rather than inferred from which file extensions happened to produce that construct in the surrounding data — the old inference could undercount how often a construct's absence should count as a real negative observation, biasing conclusions toward "everyone does this" more than the evidence supported. Shape-serialization depth, statement-count, and variable-sampling limits used during raw collection are now supplied by the caller instead of being fixed constants, so they can be tuned per adopter like the rest of the feature-generation knobs. A structural guard left over from an earlier draft that could never actually trigger was removed rather than kept as dead code, and several test assertions that could keep passing even if the behavior they exist to protect were broken were tightened to check the actual computed values instead of a loose shape.
