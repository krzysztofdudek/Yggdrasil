# Adopter Guides — Responsibility

Task-oriented documentation for new and existing Yggdrasil adopters. Each document addresses a specific adoption need from installation through daily use.

## Scope

- `getting-started.md` — Installation, first-run walkthrough, and initial setup
- `cli-reference.md` — Complete reference for all `yg` commands: syntax, flags, output
- `configuration.md` — Configuration options in `yg-config.yaml` and their effects
- `platforms.md` — Supported agents and IDEs, per-platform setup instructions
- `index.md` — Documentation site entry point and navigation

## Audience

New and existing adopters: developers and teams integrating Yggdrasil into their repositories. Content must be clear, task-oriented, and approachable. Edge cases may be simplified when that aids adoption.

## Out of scope

- Internal design specifications and algorithms — belongs to `docs/concept`
- VitePress site infrastructure and static assets — belongs to `docs/site`
- Implementation details of the CLI — those live in `source/cli/`
