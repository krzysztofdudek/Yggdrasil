## [2026-09-23T22:03:42.749Z]
The CLI gained one output layer that every command reports an error through: fail and failAndExit render the structured what/why/next through buildIssueMessage, notice does the same for a non-fatal notice, and block renders a diagnostic. With the command files moved onto it, requiring buildIssueMessage to appear in the very function that writes the error would have refused the sanctioned path and pushed commands back to hand-built copies, so a call to one of those helpers now satisfies the rule exactly as a call to loadGraphOrAbort or abortOnUnexpectedError already did. The helper is recognised only as the callee of a real call in the enclosing function, never as a substring, so a function that is merely named fail cannot vouch for a raw write inside it; a drill case pins that, and another pins the output layer's own sanctioned write.
## [2026-09-24T07:24:32.093Z]
Changed by the owner's mandate that the repository's own rules enforce the CLI's one output grammar. Besides routing command errors through the output layer, the rule now refuses a string in a command file that opens a line with a label of the old grammar (a capitalised Why:, Fix:, Next:, Then:, Error:, Notice: or Warning:, or Next (this group):), because such a line is output laid out by hand around the layer that owns the lowercase labels; and it refuses a count written with a hand-rolled (s) plural, because the output layer's count and plural make a noun agree with its number. buildIssueMessage stays an allowed path: it now renders the labelled grammar itself. The corpus gained a legacy-labels case, a hand-plural case and a labelled-grammar case the old rule could not tell apart, and its output-layer case no longer writes an Error: prefix.
## [2026-09-24T13:38:16.583Z]
The hand-rolled plural check moved out of this rule into output-through-layer, which covers every file of the shipped source tree rather than the command files alone and also catches hand-built counts; keeping a second copy here would have meant two rules to update whenever the definition of a hand-rolled plural sharpens. This rule keeps what is its own: errors through the output layer and no line in the old grammar.
